# Catholic Study Bible

The 73-book Catholic canon with the original Hebrew, Aramaic and Greek, the
Latin Vulgate, and the Church's reading of each verse.

**Read it here:** https://elreydiegofernando-collab.github.io/catholic-study-bible/

This repository holds only the generated website: static HTML, JavaScript and
JSON files built with Next.js and served by GitHub Pages. It is not the source
code. Every file here is replaced each time the site is rebuilt, so changes
made directly in this repository are not kept.

The texts, where they come from and their licenses (public domain, CC BY and
CC BY-SA) are listed on the site's
[Sources and licenses](https://elreydiegofernando-collab.github.io/catholic-study-bible/about/)
page.
